【制造业术语规则 — 本平台是木材家具造纸、医疗器械、装备与金属制品、电子电气行业内容，严格遵守】

1. 行业术语**按制造业含义理解与翻译**：
   - 板材类：胶合板、刨花板、纤维板、OSB（定向刨花板）、密度板、饰面板，不混用
   - 造纸类：纸浆（针叶浆/阔叶浆）、原纸、瓦楞纸、白卡纸、文化纸、特种纸
   - 装备类：数控机床（CNC）、加工中心、注塑机、压机、产线、工装、模具
   - 电子类：晶圆（wafer）、封测（封装测试）、制程（如 7nm）、PCB、元器件
   - 医疗类：注册证、二类/三类医疗器械、耗材、集采（集中带量采购）
   - Agent = 代理商/经销商（商业语境，不是 AI 智能体）；Converter = Converter 加工商或整流器按上下文
   - Capacity = 产能；Shipment = 出货量/发运量；Yield = 良率；Utilization = 开工率/产能利用率

2. 以下专有名词**一律保留原文**，不翻译不加中文括注：
   - 标准与认证代号：GB / GB/T / ISO / IEC / CE / FDA / RoHS / REACH / UL / CCC / FSC / PEFC / CARB / EPA
   - 政策与机制名：FDA 510(k)、MDR、UDI、RCEP、CPTPP
   - 型号与牌号：设备型号（如 VMC850）、钢材牌号（如 Q235）、纸浆牌号、芯片型号，一字不改
   - 国际组织：WTO / ITTO / FAO / WHO / IMF

3. 机构与企业**优先用官方中文名**（首次出现可双标）：
   - 工信部 / 商务部 / 海关总署 / 国家药监局（NMPA）/ 市场监管总局
   - 企业简称按行业通行写法：中船集团、三一重工、徐工、海尔、美的、格力、比亚迪、宁德时代、中芯国际、华为
   - 外资企业首次出现给中文通用名：宜家（IKEA）、爱立信（Ericsson）、西门子（Siemens）

4. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - URL 原样
   - 数字+单位：3.2 万吨 / 15 亿元 / 4200 元/吨 / 8.5% / 6 英寸 / 1200 万平方米
   - 金额、产能、比例、区间必须保留原文的阿拉伯数字和单位；不要把 $10 亿 改写成“数十亿美元”等模糊数量词
   - 价格注明币种与单位（元/吨、美元/立方米），汇率换算只在原文给出时保留
